BUG-001 [CRITICAL] — ReferenceError: Validate is not defined
  Affects: Assignments, Attendance, Academic Records
  Files  : frontend/js/assignments.js (lines 395-466)
           frontend/js/attendance.js  (lines 96-419)
           frontend/js/cgpa.js        (lines 186-205)
  Detail : validation.js exposes its API only as Scholaris.utils.validation —
           it does NOT attach a global Validate variable. timetable.js
           correctly creates a local alias:
             const Validate = Scholaris.utils.validation;
           but the three files above call Validate.setError(), Validate.clearError(),
           Validate.isValidDate() etc. as a bare global. Any attempt to submit
           an assignment form with an empty title, log attendance without a date,
           or trigger CGPA subject validation will throw:
             Uncaught ReferenceError: Validate is not defined
           and the whole IIFE module will crash, disabling the feature entirely.
  Fix    : Add this line near the top of each affected IIFE (after
           const Scholaris = window.Scholaris;):
             const Validate = Scholaris.utils.validation;

BUG-002 [CRITICAL] — Backend unit test failure: goal_progress_minutes
  File   : backend/tests/test_unit.py:614
  Detail : test_goal_progress_minutes_equals_weekly_total fails when run on a
           Monday. The test builds a dict with 	oday (Monday) and
           	oday - timedelta(days=1) (Sunday). The weekly window starts on
           Monday, so Sunday is excluded, giving weekly=60 not the expected 90.
           The assertion ssert weekly == 90 is wrong on Mondays.
  Fix    : Use a fixed mid-week date in the test or compute expected dynamically.

BUG-003 [CRITICAL] — Timetable: 'Add Time Slot' shows modal but grid stays hidden
  File   : frontend/js/timetable.js (line 890-892)
  Detail : #tt-output is hidden until a file is uploaded. addTimeSlot() opens
           the modal, saves the new event to schedule[], but the output section
           stays hidden so the rendered grid is invisible. The first class added
           via "Add Time Slot" (without uploading a PDF/image) never appears.
  Fix    : In addTimeSlot(), reveal the output and hide the upload zone:
             output.hidden = false;
             uploadZone.hidden = true;

BUG-004 [CRITICAL] — Attendance: course dropdown stuck on "Select date first..."
  File   : frontend/js/attendance.js (lines 42-93)
  Detail : In offline mode, courses are pulled from the timetable for that day.
           With no timetable saved, the dropdown shows only "No subjects found"
           (value "N/A"). Submitting triggers: "Please select or enter a valid
